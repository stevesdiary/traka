# API reference

The complete, interactive specification is rendered from the OpenAPI file
(`swagger.yaml`). It covers every endpoint, schema, security scheme, and error
response for:

- **External API** — `/v1/external/orders`, `/orders/bulk`, `/orders/{tracking_number}`,
  `/orders/{tracking_number}/recipient`, `/orders/{tracking_number}/confirm`, `/rides`.
- **API key management** — `/api/businesses/{business_id}/api-keys`.
- **Webhook management** — `/api/businesses/{business_id}/webhooks` and the
  deliveries audit log.

<OpenApi specUrl="/openapi.yaml" />

> The spec is the machine-readable source of truth for every endpoint on this
> site. If a guide and the spec disagree, the spec wins.

## Using the reference

1. Select an endpoint on the left.
2. Read the request schema and try it live against the **development** base URL.
3. Copy the request as **cURL**, or use the generated SDK snippets where available.

> Development interactive docs also run at `http://localhost:4000/api-docs`.
